# 🧠 Quiz R2A

A web-based **quiz application built with React and Vite**, designed to provide an interactive way to answer questions and test your knowledge.

The application uses a modern React frontend with API-based data fetching, client-side routing, and a Material UI interface.

## 🎮 Features

* 🧠 Interactive quiz experience
* 📚 API-powered quiz questions
* ⚡ Fast React + Vite development environment
* 🎨 Material UI components
* 🔀 Client-side routing
* 📡 API requests with Axios
* 📱 Responsive interface
* 🏆 Score tracking

## 🛠️ Tech Stack

| Technology   | Purpose                       |
| ------------ | ----------------------------- |
| React        | Frontend UI                   |
| Vite         | Development and build tooling |
| JavaScript   | Application logic             |
| Material UI  | UI components and styling     |
| Axios        | API communication             |
| React Router | Client-side routing           |

## 🏗️ Architecture

The application is structured as a React single-page application:

```text
quiz-r2a/
│
├── public/
│
├── src/
│   ├── components/
│   ├── pages/
│   └── ...
│
├── index.html
├── package.json
└── vite.config.js
```

The frontend communicates with the quiz API to retrieve question data and manages the quiz experience on the client side.

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed.

### Installation

Clone the repository:

```bash
git clone https://github.com/AadhilPaul/quiz-r2a.git
cd quiz-r2a
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL shown by Vite in your browser.

## 📦 Available Scripts
